# BikeStore · Tailwind Lab

UT2 · Diseño de Interfaces Web · 2.º DAW

## Empezar

1. Abre la carpeta `bicycle-shop/frontend` en VS Code.
2. Usa Node.js 22 LTS (22.12 o superior) o 24 LTS. Instala la extensión recomendada Tailwind CSS IntelliSense.
3. En la terminal integrada, ejecuta:

   ```sh
   npm ci
   npm run dev
   ```

4. Abre la URL que muestra Vite. Empieza por la sesión 1 y sigue los enunciados y enlaces de cada sesión.

## Cómo trabajar

Usa la misma carpeta durante las seis sesiones. El menú «Guía de sesiones» cambia el enunciado. Debajo siempre verás la misma vista de trabajo, que refleja tus cambios en `src/Proyecto.tsx`.

| Sesión | Objetivo |
| --- | --- |
| 1 | Comprobar la instalación y probar utilidades |
| 2 | Construir una ficha completa |
| 3 | Convertir la ficha en el punto de partida de una cuadrícula |
| 4 | Adaptar la cuadrícula y el menú del escaparate a la pantalla |
| 5 | Añadir estados de interacción y modo oscuro |
| 6 | Extraer un componente y renderizar el catálogo a partir de los datos |

Los datos y precios están en `src/features/bicycles/services/bicycles.ts`. Las tres fotos están en `src/features/bicycles/images/`. Los enlaces oficiales de Tailwind aparecen junto a cada enunciado.

Para comprobar tu entrega ejecuta `npm run build` desde `frontend`.
